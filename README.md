# MultiPandOS

MultiPandOS is an educational multiprocessor operating system , an evolution of PandOSplus and part of a long lineage of academic operating systems (such as Kaya and ICARO). The system is designed for the µRISCV architecture and is structured into six levels of abstraction based on Dijkstra's THE model.

To compile the project:
```bash
cmake -B build
cmake --build build
```
